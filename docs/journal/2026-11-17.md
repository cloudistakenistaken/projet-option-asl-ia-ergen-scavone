## Ce que nous avons fait

Nous sommes partis du constat que le README demandait plusieurs commandes
successives et qu'un oubli pouvait empêcher la reconstruction du projet. Nous
avons donc créé `scripts/setup.sh` pour automatiser le parcours complet :

1. installation des dépendances Python avec `make bootstrap` ;
2. installation d'Ollama s'il est absent et vérification de son serveur ;
3. téléchargement et vérification des modèles avec `make models` ;
4. création de l'index avec `make ingest` ;
5. lancement des tests unitaires et d'intégration ;
6. démarrage automatique de l'API avec `make serve` si toutes les étapes réussissent.

Le script réutilise un serveur Ollama déjà actif. S'il doit en démarrer un,
il le fait temporairement et le ferme à la fin. Nous avons ajouté la cible
`make setup` dans le Makefile et documenté la procédure dans le README.

Nous avons également ajouté à la fin du script un message indiquant l'adresse
de l'API et une commande `curl` prête à copier. Pour lire proprement la réponse
JSON dans le terminal, la commande utilise `python3 -m json.tool`.
