## Ce que nous avons fait

Nous avons remplacé le parcours de démonstration uniquement au terminal par une
page web locale servie par FastAPI sur `/`. Elle permet de saisir une question,
d'envoyer la requête au endpoint `/ask`, puis d'afficher la réponse, les sources
récupérées et les durées de recherche et de génération.

Nous avons ajouté un affichage en texte brut pour la réponse et les extraits :
le navigateur utilise `textContent`, donc une balise reçue du modèle n'est pas
interprétée comme du HTML. Cette vérification répond aussi au scénario LLM05 de
la fiche J3. La limite de 1 000 caractères est conservée côté API.

Nous avons ajouté un test HTTP qui vérifie que la page est servie et qu'elle
utilise l'affichage sûr. Le README explique maintenant d'ouvrir
`http://127.0.0.1:8000` après `make serve`, tandis que l'API reste disponible
pour les scripts et les tests.

## Vérifications et limites

Nous avons contrôlé la route web et son test. Le modèle local et Ollama doivent
toujours être préparés comme indiqué dans le README ; la page ne remplace pas
le serveur FastAPI, elle remplace seulement l'usage manuel de `curl`.
L'authentification et les droits documentaires restent à traiter dans les
jalons suivants.
